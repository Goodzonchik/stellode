# Контекст

Система предназначена для хранения, планирования и анализа взаимодействий между бизнес-модулями/компонентами приложения. 

Система должна поддерживать:
- версионирование Feature, Component и Application; контракты между версиями компонентов внутри Feature;
- организационные связи (юниты, команды, сервисы);
- бизнес-связи между сервисами и фичами;
- историю версий и черновики;
- композицию фич из компонентов;
- связи между фичами разных сервисов и юнитов;
- запросы анализа влияний и зависимостей.

Основана на графовой модели (Neo4j, язык запросов Cypher).
