# API: состав услуги (`AGGREGATES`)



Нормативная модель: [spec.md §2.1](./spec.md). UI-сценарии: [ui-spec.md §5.6, §6](./frontend/ui-spec.md).



## Хранение причины снятия



В текущей реализации граф в Neo4j — источник правды по рёбрам `AGGREGATES`; опциональная **причина снятия** хранится как свойство ребра **`deleted_reason`** (строка) вместе с **`deleted: true`**.



## Эндпоинты

Описание эндпоинтов, тел запросов и кодов ошибок — в Swagger (`/api/docs`, тег **Services**). Любая мутация состава или описания **архивного** сервиса запрещена (`409`).

## Диаграмма сервиса и режимы `on-prod` / `draft`



`GET /api/diagrams/service/:id` принимает query **`projection`**:



- **`on-prod`** (по умолчанию, если параметр опущен): в ответе только **активные** рёбра `AGGREGATES` (`deleted` отсутствует или не `true`); ноды `Feature`, связанные только снятыми рёбрами, **не** включаются.

- **`draft`**: query `?projection=draft` — в ответе также рёбра с **`deleted: true`** (история снятия из состава); на фронте такие связи визуально отличаются (пунктир / приглушённый цвет).



Impact API для сервиса в контексте диаграммы использует ту же логику режима, что и для остальных сущностей (`inferDiagramImpactMode`).
