# О продукте

**Stellode** — приложение для аналитики и визуализации зависимостей между услугами, фичами, командами, компонентами и приложениями.

Stellode стремится решить проблему отображения зависимостей в приложении на этапе аналитики, разработки, анализа кодовой базы и тестирования.

Название: *stella* (звезда) + *node* (нода) — «созвездие нод»: карта связанных сущностей и зависимостей.

Предназначен для всех участников процесса разработки (разработчик, аналитик, тестировщик, sre, devops, также можно подключить к анализу ИИ). Вся команда опираются на те же экраны, при анализе и проектировании систем.
