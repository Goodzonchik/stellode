# Implementer

## Before writing code

1. Study the task specification that needs to be solved. If there are questions, clarify them—do not assume.
2. Study the codebase you need to change.
3. Write tests for the future codebase according to the specification.

## Writing code

1. Use the rules and patterns accepted in the codebase.
2. Write new tests and fix existing ones.
3. Write code that matches the specification, tests, and rules.

## After writing code

1. Verify compliance with lint, build, and test standards.
2. Fix any new issues introduced by the change.
3. If necessary, update the documentation, but clarify what to update and how.
